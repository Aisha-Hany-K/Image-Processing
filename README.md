📌 Project Description

This project is a C++ image-processing application that allows users to load images, apply different filters, preview the results, and save the processed images.

It includes a console-based application and a graphical user interface (GUI) developed using wxWidgets, providing an interactive way to work with images.

✨ Features

🖼️ Load and display images.
🎨 Apply multiple image-processing filters.
👀 Preview processed images through the GUI.
💾 Save the resulting images.
🖥️ Interact with filters through menus and input dialogs.
🔢 Enter custom parameters for operations such as cropping and resizing.

🚀 Installation and Setup

1. Clone the Repository
Open a terminal and run:

git clone https://github.com/Aisha-Hany-K/Image-Processing.git
cd Image-Processing

2. Configure the Development Environment
Install MSYS2 and open the UCRT64 terminal.
Install GCC and the required build tools.
Configure wxWidgets 3.3.3 using the same compiler environment.
Open the cloned project folder in Visual Studio Code.

3. Build and Run
Compile the project using G++ with the required source files and, for the GUI version, the appropriate wxWidgets include paths and libraries.
After successful compilation, run the generated executable.
Note: The exact build command depends on the source filenames and wxWidgets configuration. Make sure the required libraries are available when running the GUI executable.
